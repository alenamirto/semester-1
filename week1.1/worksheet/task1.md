# Terminal Commands

You have been introduced to a variety of terminal commands this week – fill out the table with an explanation for each command which says what it is used for.

You may find it useful to run these commands in the terminal of Codespace to remind yourself.

You should put your explanations between the \| \| characters.

You can complete this task on the worksheet pdf if you prefer.

|     Command                 |     Explanation    |
|-----------------------------|--------------------|
|     pwd                     | shows the current location of the terminal |
|     ls                      | Lists everything in the current directory
|     cd directory_name       |  Move into the directory referenced by directory_name
|     cd ..                   |  Move up by one directory level
|     cd -                    |  Move down by one directory level to the previous directory
|     mkdir directory_name    |  Makes a new empty directory named directory_name
|     touch filename          |  Makes a new file called filename
|     git status              |  Displays the state of the working directory (what’s going on with git add     and git commit)
|     git add -A              |  “git add” stages your changes and tells git you have done some work to save. -A saves all the work 
|     git commit -m ""        |  “git commit” bundles the changes into one ‘commit’ and “’-m” lets you set the commit message (what a git commit changed and why)
|     git push                |  Sends changes back to the remote github server where the changes will be stored
|     git pull                |  Integrates changes from a remote repository into the current branch
